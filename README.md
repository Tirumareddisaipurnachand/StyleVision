# StyleVision

AI-powered personal styling assistant built with Streamlit and Gemini.

## About

StyleVision helps users explore outfit and clothing recommendations through an AI-powered chat experience. Users can upload an image or ask styling questions and receive personalized suggestions based on their preferences.

## Features

- AI-powered styling suggestions
- Image upload for outfit analysis
- Interactive chat interface
- Personalized clothing recommendations
- WhatsApp summary notifications
- Clean and responsive UI

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Twilio WhatsApp API

## How It Works

1. Open StyleVision.
2. Upload an outfit image or ask a styling question.
3. The AI analyzes the request.
4. StyleVision provides clothing and styling suggestions.
5. Users can receive a summary through WhatsApp.
